# Student Grade & Scholarship Checker

A beginner Java console application that calculates student grades, pass/fail status, and scholarship eligibility.

## Features

- Student name input
- Marks validation (0-100)
- Grade calculation
- Pass/Fail check
- Scholarship eligibility
- Student report generation

## Technologies

- Java
- IntelliJ IDEA
- Scanner
- If-Else Statements

## Sample Output

```
---------------------------
      STUDENT REPORT
---------------------------
Name: John
Marks: 91
Grade: A
Result: PASS
Scholarship: Eligible
---------------------------
```
